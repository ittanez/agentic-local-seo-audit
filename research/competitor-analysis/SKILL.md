# Competitor Deep Analysis Framework

Analyze each competitor (3-5) across ALL of these dimensions:

## 9 Analysis Dimensions

### 1. Identification & Profiling
- Confirm they actually rank for target keywords in target location
- Map site structure, page count, domain age signals, authority level
- Primary services vs. client's services

### 2. Technical SEO Profile
- CWV estimates, mobile experience, schema usage, URL structure
- Site architecture depth, JS rendering approach

### 3. Content Strategy
- Total volume, publishing frequency, content types, depth, freshness
- Topic cluster strategy, unique content assets, UGC presence

### 4. Keyword Strategy
- Primary keywords (from titles, H1s, URLs), long-tail coverage
- Featured snippet ownership, PAA presence

### 5. Backlink & Authority
- Link quality signals, most-linked pages, digital PR patterns
- Local citations, partnership links

### 6. Local SEO Profile
- GBP completeness, review count/rating/velocity
- Citation consistency, location pages, local content strategy

### 7. AI Visibility
- AI Overview presence, ChatGPT/Perplexity/Gemini mentions
- Content structured for AI extraction, entity presence

### 8. Social Media Presence
- Active platforms, follower counts, engagement rates
- Content strategy, community building, reviews

### 9. SERP Feature Ownership
- Local pack, featured snippets, PAA, image pack, video carousel
- Knowledge panel, sitelinks, FAQ rich results

## Output: Competitor Scorecard
Rate each dimension 1-10 for client AND each competitor.
Produce: gap table, exploitable opportunities, threats, quick wins.
