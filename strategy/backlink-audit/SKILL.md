# Backlink & Link Profile Audit Framework

## Current Profile Assessment
- Referring domain count/quality, anchor text distribution
- Follow/nofollow ratio, link type distribution, link velocity
- Most-linked pages, toxic/spammy links

## Competitor Comparison
- Volume, quality, common links, unique competitor links
- Link building strategy patterns per competitor

## Link Gaps & Opportunities
- Directories linking to competitors not client
- Broken link building opportunities
- Unlinked brand mentions
- Local link targets (media, orgs, events)
- Digital PR angles, content-driven link earning
- Partnership, association, certification links

## Toxic Link Assessment
- PBN, foreign spam, comment spam, link schemes
- Disavow recommendations

## Link Building Strategy
- Prioritized targets, content assets to create
- PR campaign concepts, velocity targets
