# On-Page SEO Audit Framework

## Title Tags (Every Key Page)
- Unique? Primary keyword near beginning? 50-60 chars?
- Brand name? Location for local pages? Compelling for CTR?
- Service + Location formula for service pages

## Meta Descriptions (Every Key Page)
- Unique? 150-160 chars? Keyword + CTA + location?
- Phone number where relevant? Value proposition communicated?

## Header Tags (H1-H6)
- One H1 per page with primary keyword? Unique across site?
- Logical hierarchy (no skipping levels)? Descriptive, not generic?

## Content Optimization (Per Page)
- Keyword in first 100 words? Natural density (1-2%)?
- LSI terms and NLP entities used? Search intent fully satisfied?
- More comprehensive than current #1 ranking page?
- Unique value offered? Proper readability level?
- Multimedia included? Content freshness?

## Internal Linking (Deep Analysis)
- Hub-and-spoke model? Service↔blog cross-linking?
- Descriptive, varied anchor text? Orphan pages identified?
- Most important pages receive most internal links?
- No critical page > 3 clicks from homepage?

## Image SEO
- Descriptive alt text? Descriptive file names? WebP/AVIF format?
- Responsive (srcset)? Lazy loading? Dimensions specified?
- Geo-tagged for local SEO?

## E-E-A-T On-Page Signals
- About page (detailed, team bios, credentials)?
- Author bylines with author pages? Trust badges?
- Testimonials, case studies, real photos?

## CTAs
- Clear CTA every page? Click-to-call (tel: link)?
- Above fold on mobile? Service-specific CTAs?
