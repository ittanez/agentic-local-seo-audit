# Entity Audit Framework

## Business Entity Assessment
- Recognized as distinct Google entity? Knowledge Panel?
- Wikidata entry? Wikipedia mention?
- sameAs connections (website ↔ profiles ↔ directories ↔ GBP ↔ Wikidata)
- Consistent attributes across web (name, type, location, founding)

## Content Entity Analysis
- Extract entities from client's key pages
- Extract entities from competitor pages
- Compare: missing critical entities? Wrong/irrelevant entities?
- Entity salience: right entities most prominent?

## Entity Types
- Person, Place, Organization, Service, Concept, Event entities

## Entity Optimization
- Schema for all key entities
- Consistent naming, relationship mapping
- Co-occurrence optimization, sameAs strategy
