# UX & CRO Audit Framework

## UX Assessment
- Navigation (2-click access), above-fold content, trust signals
- Loading experience, error handling, accessibility

## Conversion Paths
- Primary actions: calls, forms, bookings, chat
- Click depth to conversion? Form analysis? Click-to-call prominent?
- Multiple conversion paths? Social proof near conversion points?

## Analytics & Tracking
- GA4 installed + configured? GSC verified?
- All conversions tracked? Call tracking? Form tracking?
- Key interactions tracked? Regular reporting?
