# Topical Gap Analysis Framework

## Complete Topical Universe
- Map entire topical universe: Parent (pillars) → Subtopics (clusters) → Supporting topics
- Cross-reference: client coverage vs. competitors vs. ideal map

## Cluster Completeness
Per cluster: pillar page exists? Quality? Cluster pages X/Y complete?
All internally linked? Orphaned cluster content?

## Semantic Coverage
- Missing entities, concepts, questions, processes, synonym variations

## Deliverable: Complete Topical Map

├── CLUSTER: [Subtopic]

│   └── Supporting: [Page idea]

Priority: 1-5 | Relevance: H/M/L | Competition: H/M/L
