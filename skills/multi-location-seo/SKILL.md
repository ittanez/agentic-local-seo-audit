# Multi-Location SEO Audit
- Separate verified GBP per location? Each independently optimized?
- Unique location pages (not template duplicates)?
- URL structure? Store locator? Per-location schema?
- Per-location reviews, citations, content?
- Geo-siloed content strategy?
- Cannibalization prevention between locations?
